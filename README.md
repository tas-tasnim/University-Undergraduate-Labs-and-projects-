#### Viva 1

| File | What it does |
|---|---|
| `Q2.java` | 36-month credit-card repayment simulator: monthly interest, a 5% / RM 50 minimum payment, an optional payment holiday with a late fee, and year-end balances |
| `Q3.java` | Parcel shipping calculator: normalises Malaysian and international postcodes, maps them to zones, validates weight and `LxWxH` input, and charges by the larger of actual and volumetric weight with bulk discounts and heavy-parcel surcharges |
| `Q4.java` | Solar EV charging hub: a menu loop over four vehicles that computes energy delivered (90% efficiency), charging time, cost and a final report, and handles partial charging when the hub battery runs out |
| `Q6.java` | Two-robot command simulator: uppercase letters move robot P and lowercase move robot Q on a grid; tracks meetings, returns to the origin and maximum Manhattan distance, then simplifies the command string by cancelling opposite moves and full 360° turns |
| `Q1.java`, `Q5.java` | Placeholders, not attempted yet |

This is a NetBeans project. To run it, open the folder in NetBeans or compile any file with `javac`.
